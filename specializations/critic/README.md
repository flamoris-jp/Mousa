# Mousa Critic (planned)

Critic is a **family of distinct evaluations**, not an infallible taste oracle:

1. **Validity:** MIDI/event format and bounded consistency checks.
2. **Features:** phrase variety, repetition, rhythmic motion, rest/interval statistics.
3. **Preferences:** human pairwise A/B/tie/neither comparisons with use-case and editing reasons.
4. **Similarity risk:** near-copy diagnostics and provenance references; no automatic legal verdict.

Preference data must be human-provided or transparently labeled synthetic. Candidate-selection and final held-out evaluation sets must remain separate. Never substitute a high model score for a listening test.
