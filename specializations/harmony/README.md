# Mousa Harmony

Learn and propose chord functions/progressions, harmonic rhythm, tension and
release. Harmony does not decide final MIDI tracks or change Cantabile state.
Future learning must support uncertainty/unknown harmony and must not infer
that atypical chords are automatically errors.

## Implemented foundation

The experimental [degree-relative chord progression foundation](../../docs/HARMONY_FOUNDATION.md)
provides explicit root/quality/duration values, four major-key templates,
bounded seeded rule variations, and matched MIDI A/B fixtures. This is a
deterministic baseline for later harmony learning, not a trained specialist.
