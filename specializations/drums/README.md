# Mousa Drums (planned)

Train drum-rhythm specialists on bounded bar-level patterns. Proposed inputs: BPM, time signature, section, energy, preceding bars and optional bass/chord summary. Proposed output: kick/snare/hat/accent and velocity proposals.

Drums is a practical early creative proof for Maidionis because discrete rhythmic grids can be evaluated with clear baselines, but human preference and groove character remain separate goals.
