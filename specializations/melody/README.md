# Mousa Melody (planned)

Bounded melody suggestion and motif development. Proposed inputs: meter, tempo, section, note range, harmonic context, previous phrase, optional style constraints. Proposed output: note events or a bounded variation proposal, without any authority to write a project.

First research: learn rests, intervals and note onsets separately from note sustains; compare against a fixed statistical baseline on held-out composition families. Keep originality/similarity analysis independent of next-token accuracy.
