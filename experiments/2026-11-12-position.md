## Design and provenance

No external MIDI or audio is committed. All six files pass intake and the narrow
cross-split normalized-full-melody and transposed-eight-onset duplicate screen.

Compare single versus four-source training; no clock context versus within-bar
versus within-bar + four-bar-cycle context; empirical versus rest/note-typed
train-only duration prior; unlimited versus maximum twelve consecutive rest
steps. Five fixed seeds (7,17,29,43,59), 6/8, 96 steps/eight bars. Relative pitch
and smoothing fixed. All 120 candidates generated in about six CPU seconds,
under the five-minute CPU research limit. No neural or GPU computation.

An initial empirical-prior run showed the rest cap never binding for these
seeds. The typed-prior condition was then added as an explicitly exploratory
stress test, not pretended to be preregistered before seeing that result. Final
configuration/code hashes are saved before the final factorial run. It was
repeated, with every metric and MIDI hash identical excluding timing/RSS.

## Implementation boundaries

`PositionEventModel` uses meter + elapsed sixteenth-grid position and optional
four-bar-cycle index; backoff is position+previous event, position counts, then
unchanged melodic control. Flags off exactly reproduce control distributions
and NLL (unit-tested). Meters do not share position keys. Song clocks and pitch
interval history reset per source. Fixed evaluation support remains 3,328.

**A clock cycle is not an inferred musical phrase.** Pickup/anacrusis alignment
has not been annotated: MIDI zero is assumed the metrical origin. Hence these
are clock-conditioned results, not validated strong-beat/phrase modeling.
The twelve-step silence cap is an explicit generation policy. Invalid rest
lengths are masked and joint probabilities renormalized, not silently clipped
into repeated rests. Evaluation NLL does not apply the mask. This does not mean
people prefer the cap or that the model learned appropriate pauses.

## Findings (not artistic ratings)

For relative pitch + empirical duration, known diagnostic NLL/event:

| Training / context | 2247 (dev, observed) | 2245 (test, observed) |
|---|---:|---:|
| one / none | 6.4325 | 6.4413 |
| one / bar | 4.6756 | 5.4156 |
| one / four-bar cycle | 6.3378 | 5.1054 |
| four / none | 7.2086 | 7.0925 |
| four / bar | 4.7598 | 5.5617 |
| four / four-bar cycle | 6.6563 | 5.2965 |

More sources **worsened** these known diagnostic NLLs, though output density
increased: no-position empirical onset counts changed 31/10/29/26/24 to
32/20/33/33/31. Do not mistake density for attractiveness or assume simply adding
data improves fit to another repertoire. The single-source model has no 6/8
training; its 6/8 generation exactly backs off regardless of position flags,
a useful negative control. Multi-source bar/cycle conditions do change output.

The empirical-prior cap produces no MIDI changes for these five seeds. In the
typed-prior multi-source condition, seed 43 has 18 consecutive rest steps under
bar context and 24 under four-bar context. With the explicit cap these become
11 and 4 respectively. All 60 capped samples have at most 12 consecutive REST
steps. Since masking changes the distribution before sampling, other events
may change even when the unconstrained sample had no overlong pause. This is
not a paired local repair preserving every other note.

Long held notes remain a separate source of sparsity and are measured as
`longest_note_steps`; rest policy alone does not solve all sparse melodies.
