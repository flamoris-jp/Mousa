# Optional private quantity comparison

Four opaque12-second clips use seed0 from each of the three single-family
conditions and the full four-work condition. No singleton was picked by its
predictive score or its sound. Order is randomized with seed20261121; the method
key stays outside Git. The researcher knows methods, so this is not double-blind.

All clips preserve original overlapping notes/gates,120BPM and output silence.
They use the same analytic sine/harmonic renderer and gain, with no external
sound recordings, soundfont or individual loudness normalization. Zero clipping
and repeat byte identity were checked. These are previews, not actual Cantabile
renders. The narrow source-copy guard passed, but legal/perceptual originality
and public release are not cleared. Do not alter a live Cantabile project.

The full-data clip reproduces an earlier generated MIDI. These are known
exploratory examples, not fresh independent samples. Training event counts,
content, source families and pitch vocabulary differ together. Preference cannot
be attributed solely to the number of works. Only one seed per condition is
heard; no population claim or model selection follows from a single listener.
