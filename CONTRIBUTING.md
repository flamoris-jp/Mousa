# Contributing to Mousa

Thanks for helping teach small music AIs to listen, learn, and compose.

1. Open or reference an Issue for changes affecting task semantics, contracts, training or dataset policy. Work in a branch and propose a PR.
2. Read [AGENTS.md](AGENTS.md), [README.md](README.md) and [the architecture](docs/ARCHITECTURE.md). Keep core training generic in Maidionis, music semantics in Mousa, workflow authority in AI Runtime, and editable MIDI projects in Cantabile.
3. Provide tests and record actual commands/results, not projected success. If results are preliminary, say so.
4. Record source URL, composition/arrangement identity, author/rights status, license terms, download timestamp, hashes, transformation chain and split assignment for any datasets and fixtures.
5. Include negative examples and evaluation failure cases. Compare against a simple baseline and a held-out, composition-family-separated split.
6. Do not commit credentials, private content, large data, copyrighted MIDI without rights review, or model weights of uncertain provenance.

Code contributions are Apache-2.0 by default. Non-code materials have independent licensing. No guaranteed individual support is offered.
